# CSA09-192324214-Assignment1

Java 17 reference implementation scaffold for the Campus Smart-Parking assignment. Each Task folder is independently runnable; Task 10 uses a package-based source layout. Review the source, understand it, and adapt the written analysis and tests to your own verified results before submission.

## Compile and run

Use JDK 17 or newer. Open a terminal in the task folder and run `javac FileName.java` followed by `java ClassName`. For Task10, from `Task10`, run `javac -d out src/parking/model/*.java src/parking/service/*.java src/parking/app/*.java` then `java -cp out parking.app.Main`.
